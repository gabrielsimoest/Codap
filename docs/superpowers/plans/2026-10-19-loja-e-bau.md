# Loja funcional e baú surpresa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gastar Bits com saldo validado no servidor: Dica instantânea, Dobro de XP e Baú Surpresa (aulas exclusivas numa coleção), com o acervo inicial de 6 aulas.

**Architecture:** Rotas autenticadas `/shop` e `/collection`, tudo online e na mesma transação da cobrança (usuário travado). O `/sync` passa a dobrar o XP dentro das janelas de boost e a recusar aula do baú não revelada. O app ganha o serviço da loja, a coleção por React Query e os estados visuais.

**Tech Stack:** Fastify + Prisma + `node:test` (API); Expo/React Native + zustand + React Query (app); Vite/React/zod (dashboard).

**Spec:** `docs/superpowers/specs/2026-10-19-loja-e-bau-design.md`

## Global Constraints

- Sem commits sem pedido; nunca ler `.env`; nunca fazer eject do Expo.
- Preços (no servidor): Dobro de XP **200**, Dica instantânea **300**, Baú **500**. Boost: **5 minutos**. Pesos do baú: aula 40, dica 25, dobro de XP 20, 250 Bits 15; garantia de aula após **2** baús sem aula.
- Toda cobrança é um decremento condicional (`bits >= preço`) na mesma transação do efeito, com `SELECT … FOR UPDATE` no usuário; saldo insuficiente é 402, nunca saldo negativo.
- Aula do baú: `is_chest = true`, `min_level` nulo, fora de `GET /modules` (salvo `includeChest=true` em desenvolvimento).
- Todo endpoint novo ou alterado atualiza Swagger e testes; imports relativos da API com `.js`; instalar dependências só pela raiz.
- Conteúdo pedagógico: pt e en, código com no máximo 30 caracteres por linha, exemplos executados antes de gravar, `content` validado contra os schemas do dashboard, `seed.ts` atualizado (`seed:generate` + `seed:check`). **Não publicar `content_version`.**
- Mudança de UI do dashboard: `pnpm dash:verify`.

## Review Focus

1. Duas compras simultâneas do mesmo usuário nunca gastam o mesmo saldo duas vezes nem deixam o saldo negativo.
2. Compra recusada (402/409) não cobra nada nem entrega nada.
3. Aula do baú **não** aparece em `GET /modules` (nem para quem a revelou) e **não** vem em `GET /collection` antes de revelada.
4. Lição do baú não revelada não paga XP no `/sync` (`lesson_locked`), e o lote segue.
5. Evento dentro da janela de boost paga o dobro (inclusive offline, depois), fora dela não, e o app calcula o mesmo localmente.
